# **App Name**: OneStop Agent

## Core Features:

- Intent Understanding: Understand user intent (buy, renew, claim, compare) and the type of insurance needed using AI, then extract all the info from user text.
- Policy Comparison: Compare insurance plans (motor, health, property, life) based on user needs.
- Recommendation Generation: Generate personalized insurance recommendations with cost, value, and reliability using a reasoning tool.
- Renewal Management: Manage policy renewals, track payments, and alert users on policy expirations via dashboard or other service.
- Claims Handling: Facilitate and track insurance claims, guiding users through the process.
- Payment Integration: Integrate with M-Pesa API for seamless payment processing.
- Document Generation: Generate necessary policy documents and forms.

## Style Guidelines:

- Primary color: Deep teal (#008080) to convey trust and security. Teal aligns with insurance themes, giving a professional feel without being overly corporate. Note: currently only Google Fonts are supported.
- Background color: Light gray-teal (#E0F8F8) to provide a soft, neutral backdrop that complements the primary color and avoids harsh contrast.
- Accent color: Warm coral (#FF7F50) to highlight calls to action and important notifications, creating a balance with the cool teal tones.
- Headline font: 'Playfair', serif. Body font: 'PT Sans', sans-serif. 'Playfair' for an elegant, high-end feel in headlines. 'PT Sans' provides clear and readable body text.
- Use clean and professional icons to represent insurance types, actions, and notifications.
- Maintain a clean and structured layout for easy navigation and clear presentation of insurance options.
- Use subtle transitions and animations to enhance user experience and provide feedback during interactions.
